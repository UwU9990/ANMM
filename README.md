# About:
This menu has many options for Nullscape

## World:
### KillVoid Visible:
This makes the barrier at the bottom of the map (KillVoid) visible

### Beacon Visible:
This makes the beacon in the center of the map (Beacon) visible

## Movement:

### Noclip:
This allows basic noclip

### Fly:
This allows basic flight

## Hitbox:

### Hitbox Size Zero*:
This changes the hitbox's size to the minimum (0.001)

### Hitbox Visible:
This makes the hitbox visible

### Disable Hitbox:
This functions as a god mode

## Debug:

### Print Hitbox Pos:
This was the first button in the whole menu, it logs the hitbox position to the console every 0.1 seconds when toggled on

### Test Notify:
Tests if the notification system from the game works

### Test Status:
Tests if the game can connect to the Github servers (useful for checking if your client can check for updates)
